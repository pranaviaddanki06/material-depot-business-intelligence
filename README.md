# Material Depot Business Intelligence

A self-initiated Business Analyst case study focused on pricing, category performance, experience-centre funnels and decision support for a home-interior retail environment.

## Important data note
This project does **not** use Material Depot internal data. Transaction, cost, store and competitor metrics are simulated for demonstration. Publicly observable company/category context is used only to frame the analytical questions.

## What the project demonstrates
- Pricing Competitiveness Index and price-opportunity logic
- Revenue, gross-margin, AOV and mix analysis
- Store / experience-centre scorecards
- Visitor → consultation → lead → quote → order funnel analysis
- Evidence-backed recommendation framing
- AI-analyst interaction pattern without exposing private data
- Clear separation of observed facts, assumptions and analyst-defined thresholds

## Business questions
1. Where may pricing need investigation?
2. Which collections are driving profitable growth?
3. Which experience centre has a funnel issue?
4. What evidence should be checked before changing a commercial lever?
5. What internal data would be required to operationalise the model?

## Stack
Next.js, TypeScript, CSS, deterministic simulated data and a decision-oriented dashboard interface.

## Portfolio positioning
The project is deliberately designed as a working analyst case study rather than a generic dashboard template: every visual is tied to a commercial question or next action.
